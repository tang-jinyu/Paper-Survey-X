# 调研表格 Schema（阅读指南＋九列主表＋图形类）

默认 sheet 顺序：「阅读指南」「论文」「开源项目」「图形类」；按用途增加「领域版图／开题结论」「来源与核验」「存疑清单」。各数据 sheet 第 1 行独立标题、第 2 行说明、第 3 行列表头、第 4 行起正文。

## 九列主表

「论文」「开源项目」共用同一套九列表头：

| 列 | 填写要求 |
|---|---|
| 论文题目 | 英文原题（开源项目则为项目名） |
| 中文名称 | 准确翻译，可附第一作者/课题组（开源项目填中文简介名） |
| 链接 | 已验证的 DOI / arXiv / IEEE / ACM / USENIX / GitHub；显示文本必须是该论文或工程的具体名字 |
| 发表会议/期刊 | 如 DAC 2024、ACM TODAES、arXiv（开源项目填出处/归属机构） |
| 发表时间 | 精确到年月；arXiv 与正式发表并存时都注明 |
| 主要方法 | **分点 3～6 条**：用了什么技术、每步机制是什么、为何这样设计；禁止一句话概括 |
| 架构 | **分点 3～6 条**：系统流水线各环节及每环节职责；综述类写覆盖范围与分类框架 |
| 核心思想 | **分点 2～4 条**：最本质的洞察／主张，以及与前人思路的差异 |
| 对本工程可借鉴点 | 落到用户场景的某个模块／问题；指出能用在哪里、解决什么；禁止空话 |

## 阅读指南

至少包含：主题与核验日期、论文／项目／嵌入图片／工作表数量、可点击的工作表导航、建议阅读顺序、使用纪律。使用纪律应写清跨平台、跨参数集、统计口径、开放全文与复现限制。

## 分点排版约定

单元格内分点：每点一行，行首加“· ”或“1) ”，用 `\n` 换行并开启 `wrap_text`。中文宋体、英文和数字 Times New Roman；混排单元格使用富文本 run 分别设置字体。

## 样式约定

- 首行标题 14pt 加粗，列头 11pt 加粗，正文 10pt；首行标题居中，正文左对齐并垂直居中。
- 浅粉暖色：标题 `#E9B9BC`、列头 `#F1D2D4`、斑马纹 `#FFF8F6`；正文白底。
- 冻结 `A4`，列表头启用筛选；按内容自适应行高。
- 链接不得显示“官方页面”“代码仓库”“GitHub 仓库”“查看链接”等通用文案。
- 文件名：中文人类可读，如 `数字IC验证激励与覆盖率方法调研_论文与开源项目.xlsx`。

## 存疑清单格式

每条：声称的标题／出处 → 核查过的渠道 → 结论（查无实据／出处有误／真实出处是什么）。存疑条目不占用主表行。
